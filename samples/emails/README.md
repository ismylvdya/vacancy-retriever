# Образцы писем

Сюда кладутся настоящие письма-рассылки (файлы `.eml`) — по папке на отправителя:

```
samples/emails/hh_ru/gmail_1234.eml
samples/emails/linkedin_job_alerts/gmail_5678.eml
```

## Как получить образцы

```bash
.venv/bin/vacancy-retriever export-email-samples --limit 3
```

Команда только читает ящик (ничего не помечает прочитанным) и сохраняет по 3 последних письма от каждого
отправителя из `config/mail.yaml`. Нужны заполненные логин и пароль приложения в `config/.env`.

Можно и вручную: в Gmail «⋮ → Скачать сообщение», в Яндексе «⋯ → Скачать» — получится `.eml`.

## Что дальше

1. Тест `tests/test_email.py::test_sample_emails` автоматически прогоняет каждый `.eml` отсюда через парсер,
   указанный для отправителя в `config/mail.yaml`, и проверяет, что из письма получился хотя бы один элемент.
2. Чтобы письмо разбиралось без LLM-разбивки (дешевле), напишите точный парсер — пошагово в
   `docs/HANDBOOK.md`, раздел «Точный парсер письма».

⚠ В письмах бывают личные данные (имя, e-mail). Репозиторий приватный, но перед коммитом лучше
заменить их на `hidden@example.com`.
