# Стажировки, программы и волны набора

Решение пользователя 20.11.2026: хорошую стажировку пропустить нельзя, откуда бы она ни пришла. Поэтому «программа»
(стажировка, trainee-программа, новая волна / поток, «открыт набор», школа с наймом, день карьеры с открытыми
позициями) — **одно правило для всех источников**: Telegram-каналов, писем, сайтов. Никаких особых случаев «только
для писем» или «только для каналов компаний».

## Как это устроено

1. **LLM оценки** (`config/prompts/scoring.md`, раздел PROGRAMMES) по смыслу текста отдаёт запись с `kind: programme`:
   название программы, `seniority: intern`, направление → `role_category`, сроки и формат — в `summary_ru`. Программа
   **никогда не «not_a_vacancy»**: ни в обычном канале вакансий, ни в репосте, ни в дайджесте. Если непонятно, ведёт
   ли школа / курс к найму, — всё равно программа, с уверенностью `low`. Чистое обучение без найма (курс, вебинар,
   хакатон) — не вакансия. Конкретные позиции в том же тексте — отдельными записями.
2. **Код** (`pipeline/runner.py`): `facts.wave = kind == "programme"` (или письмо разбор почты назвал волной). В ленте
   — фиолетовая метка **Internship wave**; дальше программа оценивается как вакансия: группа, звёзды, аккредитация.
3. **Предфильтр** (`pipeline/prefilter.py`): заголовок со словами программы (`rules.yaml →
   prefilter.title_programme_markers`: стажировка, internship, программа, школа, набор, волна, отбор, поток…) не
   отсекается по ключевым словам (`title_deny_keywords`): «Стажировка в Т-Банке: Java, аналитика, QA» иначе отпала бы
   из-за «Java». Её читает LLM.
4. **Почта** (`config/prompts/mail.md`): письмо, где есть хоть одна открытая программа (и пункт дайджеста тоже), — `wave`;
   сомнение между «рассылка» и «волна / вакансии» решается в пользу волны / вакансий.
5. **Страховка** (`runner.programme_safety_net`): если разбор почты сказал «волна», а оценка — «не вакансия» для всего
   письма, письмо всё равно попадает в ленту программой с уверенностью `low` и пометкой «проверьте вручную».
6. **Подсказка** `params.source_employer` в `sources.yaml` (канал или сайт самой компании): чей это источник — LLM
   ставит этого работодателя, если в тексте не назван другой. На распознавание программы она не влияет.

## Где программы появляются

- Telegram: любые каналы, в том числе каналы компаний (СберСтудент, RWB Тех, Т-Образование, Ozon Team).
- Почта: рассылки стажировок (Яндекс, Авито, МТС…), Changellenge, VK Internship и любые письма про работу.
- Сайты: hirehi, hirify, карьерные сайты компаний — там программы обычно оформлены как вакансии «Стажёр».

Тесты — `tests/test_programmes.py`.
