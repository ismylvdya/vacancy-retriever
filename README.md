# 🦮 Vacancy Retriever

Персональный агрегатор вакансий для macOS. Собирает вакансии из Telegram-каналов, сайтов и почтовых рассылок,
отсеивает мусор правилами, извлекает факты через Claude (по подписке, без API-ключа) и показывает одну ленту,
сгруппированную по приоритетам: работа в Сербии с ВНЖ (IT и руками) → удалёнка у русскоязычных работодателей →
неофициальная работа → неясное.

Иконка в меню-баре → локальная страница в браузере → кнопка **Start run** → утром 10–15 минут на ленту.

Версия: **v0**.

## Установка в 5 шагов

1. Доступ к приватному репозиторию и клонирование — см. [TRANSFER.md](TRANSFER.md).
2. `scripts/setup.sh` — поставит недостающее (uv, Claude Code CLI, Python 3.12) через Homebrew и создаст `.venv`.
3. Войти в Claude Code: в Терминале `claude` → вход аккаунтом Claude (подписка).
4. (Необязательно) пароли приложений для почты — в `config/.env`.
5. `scripts/start.sh` — откроется http://127.0.0.1:18765/ и появится 🦮 в меню-баре. Нажать **Start run**.
